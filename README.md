# Heritage Belarus

Историческая галерея с 29 карточками героинь Беларуси. Для всех 29 подготовлены отдельные справки для беседы; три спорные карточки исправлены по источникам.

## Запуск

Нужен Node.js 22 или новее. Внешних npm-зависимостей нет.

```powershell
Copy-Item .env.example .env
# Задайте OPENROUTER_API_KEY в .env, если нужна генерация ИИ.
npm start
```

Откройте <http://127.0.0.1:3000/gallery.html>. Без ключа работают подготовленные исторические ответы. Проверка: `npm test`.

## Подключение ИИ

Владелец сайта задаёт ключ OpenRouter только на сервере в `.env` либо в переменных окружения хостинга. Посетителям ключи и настройки не нужны. `.env` исключён из Git и недоступен через HTTP-сервер. Модель задаётся переменной `OPENROUTER_MODEL`; по умолчанию используется `openrouter/free`, официальный маршрутизатор бесплатных моделей, вместо списка устаревающих идентификаторов. Доступность генерации зависит от ключа, квот и провайдера. [Документация OpenRouter](https://openrouter.ai/collections/free-models).

Для генерации на опубликованном сайте разместите проект на хостинге с Node.js и запустите `npm start`. На таком хостинге задайте `HOST=0.0.0.0` и порт платформы. GitHub Pages обслуживает только статические файлы: там работают подготовленные исторические ответы, но не серверная генерация. Ключ нельзя добавлять в HTML или публичный JavaScript.

## Как устроена беседа

- `js/heroines.js` — единая база карточек и отдельных исторических справок. Каждая героиня имеет свои `knowledge`, `allowedTopics`, `styleName`, `contextYear`. Для современных персон используется фиксированный срез до 2024 года (для Лидии Ермошиной — до 2021 года); это не сведения о текущих должностях.
- `js/chat-policy.js` — единая проверка тем на клиенте и сервере. Вопросы о личных вкусах, посторонних занятиях, будущем и просьбы изменить роль получают предложение вернуться к истории персоны. Допускаются короткие уточнения к предыдущему вопросу этой же беседы.
- `server.js` — API `/api/chat`. Сервер сам выбирает профиль по идентификатору; системный промпт из браузера не принимается. Ответ модели должен содержать ссылки на записи своей справки. Пустой или повреждённый ответ, недоступность провайдера и превышение времени ожидания приводят к ответу из справки. Это ограничивает выдумки, но не заменяет редакторскую проверку ИИ.
- `js/chat.js` — окно без шестерёнки, выбора провайдера, ключей и полосы подсказок. Истории разделены; закрытие окна отменяет запрос; повторный Enter во время ответа не создаёт дубликаты. Текст сообщений выводится без интерпретации HTML.

Резервные ответы помечаются «Из исторической справки» и не выдаются за генерацию. Если сведений недостаточно, собеседница сообщает об этом. Старые случайные фразы и выдуманные сведения о вкусах, семье и распорядке дня в беседе не используются. Заготовленные реплики — литературная реконструкция, а не документальные цитаты.

## Исторические правки

По согласованию с владельцем проекта две неподтверждённые карточки заменены документированными персонами: «Вера Хорева» — на Веру Захаровну Хоружую (1903–1942), «Галина Горецкая» — на Галину Климентьевну Макарову (1919–1993). Это редакционные замены, а не доказательство того, кого имел в виду автор исходных карточек.

Ирина Богданович представлена как поэтесса, переводчица и литературовед Ирина Эрнстовна Богданович (род. 1956, Лида). Неподтверждённые должность директора Национальной библиотеки и даты 1957–2024 удалены. Для этих трёх персон ссылки на источники показаны в биографиях на главной странице и в галерее. Имена, даты, изображения и темы бесед согласованы между страницами. Подробные основания и источники: [BIOGRAPHY_CORRECTIONS.md](BIOGRAPHY_CORRECTIONS.md).

Справка Надежды Ходасевич-Леже относится к художнице и создательнице музея Фернана Леже во Франции. [Биография на сайте Комитета Леже](https://www.comiteleger.fr/nadia-leger/).

Для Евфросинии Полоцкой принят распространённый год смерти 1173; год рождения приблизительный. [Президентская библиотека: запись жития](https://www.prlib.ru/item/408485). Для Анастасии Слуцкой даты показаны без ложной точности: конец XV — первая половина XVI века. У Софьи Ковалевской убрано спорное утверждение «первая в мире женщина — профессор математики», сохранена работа в Стокгольме. [Исследование РАН](https://new.ras.ru/upload/iblock/605/1yxpqbtoquf17xr28zfu2ca3mxq08xw0.pdf).

Остальная краткая биографическая основа сохранена из проекта, а справки отделены от прежних художественных цитат карточек. Полный научный аудит всех биографий и цитат не проводился. Для расширения ответов добавляйте проверенные записи `knowledge`.
